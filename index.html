Instrucciones del GM

Documentos de contexto

Sube lore, fichas de personaje o notas en .txt / .md. Solo los documentos marcados como "activos" se envían al modelo, para no gastar tokens de más.

Memoria persistente

Resumen de lo ocurrido en sesiones anteriores de esta campaña. Se envía en cada mensaje para que el GM no olvide la historia. Puedes editarlo a mano.

Ajustes del modelo

Consigue una API key gratuita en aistudio.google.com/apikey. La key se guarda solo en tu navegador (localStorage), nunca sale hacia otro sitio.

Para tu RTX 3060 (12 GB VRAM) el mejor equilibrio es gemma4:12b (~8 GB en Q4, entra entero en VRAM). Instala Ollama, ejecuta ollama pull gemma4:12b y luego ollama serve. Como esta web se aloja en GitHub Pages, el navegador llama a tu PC en localhost: arranca Ollama con la variable OLLAMA_ORIGINS=* (o el dominio exacto de tu página) para que no bloquee la petición por CORS.

Solo se envían al modelo los últimos N mensajes de la sesión actual, más la memoria resumida y los documentos activos. El historial completo se sigue guardando en tu navegador, esto solo limita lo que se paga/procesa en cada turno. Bájalo si notas que las sesiones se vuelven lentas o caras; súbelo si el GM pierde detalles recientes.
